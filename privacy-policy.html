2. Які дані ми збираємо

2.1 Дані облікового запису

  • Електронна пошта, з якою здійснюється реєстрація та вхід (через Supabase Auth)
  • Ім'я або нікнейм користувача, аватар (за бажанням)
  • Пароль зберігається в зашифрованому вигляді на стороні Supabase та не доступний нам у відкритому вигляді

2.2 Дані профілю та активності

  • Список обраних тварин
  • Історія поданих заявок на знайомство / усиновлення (включно з контактними даними, які ви вказуєте у заявці — телефон, місто, коментар)
  • Функція донатів наразі недоступна в Застосунку. Коли ми її запустимо, ми оновимо цю Політику із зазначенням платіжної системи, через яку оброблятимуться платежі. Дані банківської картки ми не бачитимемо і не зберігатимемо — вони оброблятимуться виключно платіжною системою
  • Оголошення, які ви публікуєте в Застосунку (якщо ви представник притулку або волонтер)

2.3 Push-сповіщення

  • Токен пристрою (device push token), який генерується Expo/Apple Push Notification service, для надсилання сповіщень про статус заявки, нові оголошення тощо
  • Токен обробляється через Supabase Edge Function і не передається третім особам, окрім сервісів надсилання push-повідомлень (Apple APNs / Expo Push Service)

2.4 Технічні дані

  • Логи використання застосунку (помилки, час сесій) для діагностики та покращення стабільності
  • Тип пристрою та версія ОС

Ми не збираємо геолокацію пристрою автоматично. Вибір міста для фільтрації тварин здійснюється вручну користувачем.

3. Для чого ми використовуємо дані

  • Створення та підтримка облікового запису
  • Обробка та передача заявок на усиновлення до відповідних притулків
  • Обробка донатів і надання підтвердження транзакції
  • Надсилання push-сповіщень про статус заявок, оновлення обраних тварин, важливі новини Застосунку
  • Технічна підтримка та виправлення помилок
  • Аналітика використання для покращення функціоналу (в узагальненому, знеособленому вигляді)

4. Правова підстава обробки

Ми обробляємо дані на підставі: (а) вашої згоди при реєстрації, (б) необхідності виконання договору (надання функціоналу Застосунку), (в) законного інтересу — забезпечення безпеки та стабільності сервісу.

5. Кому ми передаємо дані

Ми не продаємо персональні дані третім особам. Дані можуть передаватися виключно:

  • Supabase (Backend-as-a-Service) — зберігання бази даних, автентифікація, Edge Functions
  • Притулкам-партнерам — дані заявки на усиновлення (ім'я, контакти, повідомлення), необхідні для розгляду заявки
  • Apple / Expo Push Service — для доставки push-сповіщень
  • Платіжна система для донатів — буде додано в цей перелік разом із запуском функції донатів
  • Державним органам — виключно у випадках, передбачених законодавством України

6. Термін зберігання даних

Дані облікового запису зберігаються, поки ви користуєтесь Застосунком. Після видалення акаунта персональні дані видаляються або знеособлюються протягом [30 днів], за винятком даних, які ми зобов'язані зберігати довше за законом (наприклад, фінансова звітність щодо донатів).

9. Безпека

Ми застосовуємо технічні та організаційні заходи (шифрування з'єднання, контроль доступу на рівні Supabase Row Level Security) для захисту ваших даних від несанкціонованого доступу, втрати чи розголошення.
